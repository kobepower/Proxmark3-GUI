## 🚀 How to Use

### **Quick Start (3 Steps)**

1. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the GUI**:
   - Windows: Double-click `run_cyberninja_rfid.bat`
   - Linux/macOS: `./run_cyberninja_rfid.sh`

3. **Connect & Hack**:
   - Click "🔍 Scan Devices"
   - Select your PM3
   - Click "🔌 Connect"
   - Start using quick commands or type your own!

### **Verify Setup**:
```bash
python3 check_setup.py
```

## 🎮 Usage Tips

### **For Beginners**:
1. Use the "🔍 Scan Devices" button to find your PM3
2. Click the quick command buttons instead of typing
3. Start with "📊 HW Version" and "📡 HW Status"
4. Use "🔍 LF Search" or "🔎 HF Search" to detect tags

### **For Advanced Users**:
1. Type commands directly in the console
2. Use the Scripts tab for automation
3. Customize `config.json` for your preferences
4. Check logs in `logs/cyberninja_rfid.log`
